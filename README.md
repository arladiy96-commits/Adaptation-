# WikiFlex — эксперимент с Android WebView

В этом проекте мы меняем расположение элементов управления реального сайта, не используя API. Android-приложение загружает мобильную Википедию, а собственная панель внизу обращается к исходным элементам страницы через JavaScript.

Возможности: Главная, Поиск, оригинальное меню Википедии, Назад, Обновить страницу.

## APK с телефона
1. Перейдите в GitHub → Actions → Build WikiFlex APK.
2. Откройте успешный запуск либо нажмите Run workflow.
3. Скачайте артефакт WikiFlex-debug-apk и установите app-debug.apk.

## Ограничения
Работоспособность кнопки «Меню» зависит от актуальной HTML-разметки Википедии. Это демонстрационная сборка, а не официальный клиент Википедии. Для сторонних сайтов не включайте небезопасный JavascriptInterface.
